# Domain docs

Proyek ini memakai single-context.

- Baca GLOSSARY.md di akar proyek jika tersedia.
- Baca keputusan di docs/adr/ yang relevan dengan pekerjaan.
- Jika dokumen tersebut belum tersedia, lanjutkan.
  Domain-modeling membuatnya ketika istilah atau keputusan
  memang perlu dicatat.
- Gunakan istilah sesuai glosarium.
- Nyatakan konflik dengan keputusan yang sudah tercatat
  sebelum mengusulkan perubahan.
